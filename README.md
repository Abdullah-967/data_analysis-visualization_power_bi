# Data Analysis & Visualization with Power BI — Tutorials

Hands-on guides for getting set up with **Power BI Service** for course practice — written for classmates who don't have a work or school account.

## Tutorials

### 📘 [Get Power BI Service for Free — via Azure &amp; Microsoft Entra ID](./power-bi-service-free-setup_tutorial/README.md)

The end-to-end walkthrough: from creating a free Azure account, to provisioning a work/school user inside Microsoft Entra, to signing into [app.powerbi.com](https://app.powerbi.com) with that user. Includes Azure for Students vs Azure Free guidance, screenshots for every step, cost-safety tips, and a troubleshooting section.

**Start here** if your goal is to use Power BI Service.
